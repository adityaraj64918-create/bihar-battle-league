# Bihar Battle League — Full Web App Starter

## Run locally
1. Install Node.js.
2. In this folder run: `npm install`
3. Run: `npm start`
4. Open: http://localhost:3000

## Included
- Player registration API + database-in-memory demo
- Tournament listing and slot count
- Leaderboard/scoring API
- Announcements
- Admin forms
- WhatsApp/Instagram links
- Responsive BBL UI

## Before public launch
Replace the in-memory arrays with a real database, add secure admin authentication, server-side validation, backups, rate limiting, HTTPS, and a proper payment/compliance review for any entry-fee or prize-money functionality.
